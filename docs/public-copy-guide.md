# 泰聚達公開用詞規則

泰聚達同時是公司形象網站與商店。品牌文章可以談文化與收藏，但導覽、商品、購物、會員與客服流程必須使用一般台灣消費者熟悉的用語。

## 標準用語

| 使用情境 | 統一用語 |
| --- | --- |
| 商品列表 | 最新商品、商品分類 |
| 內容欄目 | 佛牌專欄、佛牌知識 |
| 交易 | 購物車、前往結帳、填寫訂購資料、送出訂單 |
| 訂單 | 訂單、待確認、訂單紀錄 |
| 商品資料 | 商品編號、來源紀錄、來源地區、寺院／發行單位、庫存狀態 |
| 會員 | 會員登入、會員中心、個人資料、常用收件資料、我的訂單 |

品牌故事或文化文章可在必要時使用「收藏品」與「收藏」，但不要把交易功能命名為收藏袋、保留單、典藏編號或送單索引。

## 不應顯示給顧客的內容

- SEO 覆核、快照、API、Worker、資料庫、部署平台與專案路徑。
- 版型示範、公開版同步、管理員名單及內部測試代碼。
- 大量裝飾英文標題或自造的博物館式名稱。
- 尚未實作的功能承諾，例如到貨通知、跨裝置同步或已可聯絡的客服。

本機測試提示只可出現在本機環境，並應直接說明「請勿輸入真實個資」。

## 商品與品牌事實

- 不得推測或補造公司地址、統編、客服資訊、寺院、年份、材質、庫存、價格或來源。
- 未完成核對的商品要顯示「商品資料整理中」，並遮蔽價格、庫存數字、來源細節與促銷標籤。
- 正式商品照片、替代文字、來源與 SEO 檢查完成前，商品頁維持 noindex，不加入 sitemap，也不輸出 Product 結構化資料。
- 未正式開放線上訂購前，網站使用 Organization，不宣稱為 OnlineStore。
- 佛牌內容可說明宗教與文化背景，不宣稱或保證財運、感情、健康等特定效果。

## 文章與 SEO

- 標題應直接對應使用者會搜尋的問題，避免抽象口號或過度文學化。
- 文章要有可核對的資料來源、足夠內容與實際幫助，才可解除 noindex。
- metadata、頁面標題、導覽名稱與文章 Schema 必須使用同一份已發布內容。
- 技術測試通過不代表內容可正式索引；內容真實性仍需人工確認。

## 客服與政策

- 沒有真實 LINE、電子郵件、電話或服務時間時，不顯示可聯絡的假入口。
- 配送、付款、退換貨、隱私與個資保存內容必須由實際營運者確認。
- 正式開放訂購時，要同步更新客服、隱私、配送、退換貨與結帳文案，避免不同頁面互相矛盾。
